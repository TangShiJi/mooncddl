# 0.2.1 兼容性与边界

目标为 RFC 8610 第 2、3 节及附录 A–E。旧版子集边界由本版取代。[标准追踪](STANDARD_CONFORMANCE.md) 提供实现和正反例。

| 能力 | 已交付 |
|---|---|
| 附录 B/C 语法 | 独立标准语法检查，运行时解析先检查 |
| 分组、选择、出现次数 | 命名/嵌套组、组选择、可选逗号、递归；PEG 贪婪和 first-success |
| 泛型、socket/plug、增量 | 作用域替换，空 socket、/= 和 //= |
| unwrap、枚举、cut | ~、&、^=> 及隐式字面量键 cut |
| major/Tag/prelude | 0–7、任意/指定 Tag、40 个附录 D 名称、用户覆盖 |
| 字面量 | 标准进制整数、十进制/十六进制浮点、raw/h/b64 字节、Unicode 转义 |
| 控制符 | .size .bits .regexp .cbor .cborseq .within .and .lt .le .gt .ge .eq .ne .default |
| 附录 E | JSON 数字类型统一，整数词法值精确保留 |

整数域 −18446744073709551616 至 18446744073709551615；更大数通过 bignum Tag。浮点 binary64，半/单精度按可表示性判定。NaN/无穷可由 CBOR 模型进入；JSON 仅有限浮点，小数点/指数用 binary64，整数词法值精确保留，越界失败。不提供任意精度 JSON 算术。

映射保留非文本键，比较不依赖顺序。解码器支持所有 major、定长/不定长容器和字符串、64 位整数、Tag、简单值和三种宽度浮点；拒绝重复键、非法 UTF-8、非法附加信息、截断和单值尾随字节。不提供编码器。

.size 对文本按 UTF-8 字节计数，对 uint 是容量而非编码宽度；不扩展到数组/映射。.bits 从最低位编号。.default 等于 .ne，不填值。.cborseq 将序列作为数组验证。

正则为 XSD Part 2 附录 F 完整字符串匹配，包括类别、块、XML 名称、递归集合减法、量词和选择；^/$ 为普通字符，点不匹配 CR/LF。固定 Unicode 13.0、XML 1.0 第五版名称字符，不保证与使用其他 Unicode 版本的引擎对新字符分类一致。

语法检查不查名字或扩展实现；可执行解析拒绝未知引用/未实现控制符。无效泛型、非单值控制器求值失败，不静默变 any。默认 1 MiB 源、100000 Token/容器项、10000 规则、128 深度、100 个诊断，并限制操作预算。超限可能失败，不表示语法不属于标准。

格式化覆盖可执行 AST；样例生成是部分合成工具，对复杂组、正则、嵌入 CBOR 等无法合成时明确报错，成功见证必须再校验，不减少解析/验证范围。

RFC 9165 扩展（如 .abnf/.feature）、网络服务、CBOR 编码、任意精度 JSON 算术不属于此次基础语言交付；未实现扩展明确失败。
