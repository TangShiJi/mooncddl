# MoonCDDL 0.1.0 兼容性矩阵

本表是验收边界，不使用“完整支持 CDDL”一类无法复现的表述。

| 能力 | 0.1.0 | 说明 |
|---|---:|---|
| `name = type` 规则 | 支持 | 重复规则和未知引用直接报错 |
| 预定义类型 | 支持 | `any/bool/nil/null/uint/nint/int/float/number/tstr/text/bstr/bytes/array/map` |
| 整数、文本、字节串、布尔字面量 | 支持 | 十进制/十六进制/二进制整数，`h'...'` 字节串 |
| 浮点字面量 | 不支持 | `float`/`number` 类型可校验运行时浮点值 |
| 类型选择 `/` | 支持 | 失败时输出一条聚合诊断 |
| 整数范围 `..` / `...` | 支持 | 含闭区间和上界开区间 |
| 数组、映射 | 支持 | 映射默认封闭，允许任意类型键 |
| 出现次数 | 支持 | `?`、`*`、`+`、`n*m`、`n*` |
| 标签键与显式键 | 支持 | `name: type`、`key => type` |
| CBOR Tag | 支持 | `#6.n(type)` 与运行时 `TaggedValue` |
| 控制符 | 支持子集 | `.size/.lt/.le/.gt/.ge/.eq/.ne/.and/.within` |
| 泛型参数 | 不支持 | 明确返回语法错误 |
| group choice `//` 与增量规则 `/=`、`//=` | 不支持 | Token 可识别，但 0.1.0 不解析 |
| socket/plug | 不支持 | 不做隐式降级 |
| `.regexp` | 不支持 | 返回 `UnsupportedFeature` |
| `.cbor/.cborseq/.abnf/.abnfb/.feature` | 不支持 | 不嵌入第二套解析器 |
| Base64 字节串 | 不支持 | 使用十六进制 `h'...'` |
| `\uXXXX` 转义 | 不支持 | 普通 Unicode 字符可直接出现在文本中 |
| JSON 适配 | 支持 | 对象键转为文本键；精确 IEEE-754 安全整数保留为整数 |
| 规范化格式 | 支持子集 | 对所有可解析且可格式化的 0.1.0 结构保持幂等 |
| 最小样例生成 | 支持子集 | 返回前自校验；无法生成时显式报错 |

## 组匹配语义

数组按声明顺序确定性匹配；映射条目按声明顺序消费，每个实际条目最多被一个声明消费。该策略覆盖协议中常见的固定字段、可选字段和尾部通配字段，不对高度歧义 group choice 做指数级回溯。

## 资源限制

`CddlLimits` 对 CDDL/JSON 源大小、Token、规则、递归深度、容器项和诊断数设置显式上限。默认值面向普通协议文档，可由调用方收紧。
